# Investment Fund Management System

A distributed web-based system for managing an investment fund, developed as part of university coursework at the University of Belgrade, School of Electrical Engineering.

The system uses a microservices architecture to manage user authentication, fund assets, and investment transactions.

### Features
- User registration and JWT-based authentication
- Role-based access for employees and directors
- Asset management with search and filtering
- Buy and sell order creation and approval
- Financial reporting and statistics
- Containerized services and deployment configuration

### Technologies
Python · Flask · SQLAlchemy · PyMongo · MySQL · MongoDB · Redis · Docker · Kubernetes
